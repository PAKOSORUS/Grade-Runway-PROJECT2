- **ไฟล์ที่สร้าง:** [[../01-requirements/01-spec/20261015-03-pdpa-baseline|REQ-20261015-03]]

- **การตัดสินใจเรื่องเอกสารเดิม:** แทนที่ เพราะขัดกับฉบับเดิมหลายจุด (Controller, ฐานกฎหมาย, เวลาแจ้งเหตุ, ขอบเขตสิทธิ) ผู้ใช้ไม่ระบุ จึงใช้ค่าแนะนำ
- **คำถามและคำตอบ:** Controller → มหาวิทยาลัย; ฐานกฎหมาย → ตามฉบับใหม่; วิธีจัดการเอกสารเดิม และกรอบแจ้งเหตุ/เก็บข้อความอนุมัติ → ไม่ระบุ (ใช้ค่าแนะนำ)
- **Assumptions:** แจ้งเหตุภายใน 24 ชม. ภายในมหาวิทยาลัย + 72 ชม. ตามกฎหมาย; ข้อความอนุมัติเก็บถึงสิ้นปีการศึกษาที่อนุมัติ; ปฏิเสธ 90 วันนับจากวันปฏิเสธ
- **Backlog:** แถว BL-20261015-02-1 ถึง -8 เปลี่ยนเป็น Superseded; เพิ่ม 12 แถว BL-20261015-03-1 ถึง -12
- **คำถามค้าง:** ยืนยันระยะเก็บ 3 รายการ, ผู้รับเรื่องฝั่งมหาวิทยาลัยและ SLA, ขั้นตอนคัดค้านการประเมิน, รูปแบบโอนย้ายข้อมูล, ระยะเก็บหลักฐานความยินยอม, ผู้เยาว์, AI กับ PDPA, ขั้นตอนถอนข้อความที่อนุมัติแล้ว

## 10:06 requirement-to-backlog: ตอบคำถามค้างทั้งหมดของทุกสเปก
- **ที่มา:** ผู้ใช้ให้ถามคำถามค้างทั้งหมดและตอบครบ 4 รอบ (16 คำถาม) แล้วบันทึกลงสเปก
- **ไฟล์ที่แก้:** [[../01-requirements/01-spec/20261014-02-peer-advice-chat|REQ-20261014-02]] (FR-7 แก้, FR-8 เลื่อน, เพิ่ม FR-10–14, AC-8–12), [[../01-requirements/01-spec/20261014-01-student-risk-alert|REQ-20261014-01]] (เพิ่ม FR-10–11, AC-6–7, threshold เริ่มต้น), [[../01-requirements/01-spec/20261015-01-audit-logging|REQ-20261015-01]] (เพิ่ม FR-12–13, AC-8–10, Log ดูเกรดเป็น session), [[../01-requirements/01-spec/20261015-03-pdpa-baseline|REQ-20261015-03]] (backup 30 วัน, คำคัดค้าน 7 วัน, ตารางระยะเก็บ, สถานะ DPO)
- **คำถามและคำตอบ:**
  - Mentor = ผ่านเกณฑ์ เป็นเกณฑ์เดียวกัน GPA ≥ 3.25 จากทะเบียน/LMS
  - ผู้รับ = ระบบจับคู่อัตโนมัติ; ผู้ส่ง = นิรนามต่อผู้รับ; แจ้งผู้ส่ง = in-app; ส่งใหม่หลังถูกปฏิเสธ = ได้ไม่จำกัด; SLA ผู้ตรวจ = 3 วันแล้วแจ้งเตือนผู้ตรวจ; AI = ไม่ใช้ในเฟสแรก
  - ระบบเดิม = ระดับมหาวิทยาลัย มี API; แจ้งอาจารย์ที่ปรึกษา = in-app + อีเมล; ซิงก์/ประเมิน = ทุกวัน; threshold = ค่าแนะนำ (GPA < 2.00, เข้าเรียน < 80%, ส่งงาน < 70%); เก็บเกรด = ตลอดสถานภาพนักศึกษา
  - หลักฐานลบใน Log = คง 1 ปี; IP login ไม่สำเร็จ = เก็บ ≤ 90 วัน; ดูเกรด = รวมเป็น session 30 นาที; ตรวจ admin = admin คนอื่นดูได้ ดูของตนเองไม่ได้
  - ผู้เยาว์ = ยินยอมเองได้ รอฝ่ายกฎหมาย; backup = หมุนทับ ≤ 30 วัน; คำคัดค้าน = 7 วัน ไม่ตอบ = พักแจ้งเตือนต่อได้ + แจ้ง DPO; DPO = ยังไม่แต่งตั้ง เป็นงานนอกระบบ
- **Assumptions ที่เพิ่ม:** ผู้ส่งนิรนามเฉพาะต่อผู้รับ (ผู้ตรวจ/Log ระบุได้); จับคู่ผู้รับกับนักศึกษาที่ถูกแจ้งเตือนความเสี่ยง (รายละเอียดใน design); IP ใน Log เป็นข้อยกเว้นที่ 2 ของ append-only ร่วมกับการลบ 1 ปี (วิธีทำใน design); รายการ "ลบข้อมูล" ใน Log ไม่ขยายอายุ หลักฐานระยะยาวใช้บันทึกแยก 5 ปีตาม REQ-PDPA 6.2
- **Backlog:** เพิ่ม BL-20261014-01-9/10, BL-20261014-02-7–11, BL-20261015-01-8/9, BL-20261015-03-13; แก้ BL-20261014-02-1, BL-20261014-02-6 (Deferred), BL-20261015-03-4, BL-20261015-03-8
- **คำถามค้างที่เหลือ:** ฝ่ายกฎหมายยืนยัน 72 ชม./ผู้เยาว์; แต่งตั้ง DPO (นอกระบบ); รูปแบบกันแก้ Log และวิธีลบ IP 90 วัน (design); กติกาจับคู่/จำกัดอัตราส่งซ้ำ/escalation ผู้ตรวจ; ยี่ห้อและรูปแบบ API ของ LMS/ทะเบียน; ค่า N ของแนวโน้มเกรด; กรณีมี admin คนเดียว
